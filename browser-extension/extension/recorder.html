🎙 Enregistrement des mots

Page destinée aux locuteurs natifs. Chaque mot ou phrase traduit peut être enregistré avec sa vraie prononciation. Les enregistrements restent sur cet ordinateur : rien n'est envoyé sur Internet.

Comment faire
  1. Choisir la langue.
  2. Pour chaque ligne : ⏺ Enregistrer, lire le texte en gras, puis ⏹ Arrêter. Réécouter avec ▶.
  3. Cliquer sur ⬇ pour enregistrer le fichier (nom : <id>.webm).
  4. Placer les fichiers dans extension/audio/<langue>/, relancer python3 extension/tools/build_dictionary.py puis recharger l'extension.
